One short funny line answering a prompt: the excuse a robot vacuum gives
after eating a sock.

> I don't see the problem. The sock is clean now. Spotless, even. Gone, but spotless.

The program writes that single line (83 characters) to `/output/entry.txt`,
with no trailing newline.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

## Why this line

Round 1's entry ("I thought your sock was a dust bunny with commitment
issues.") ranked 2187 of 2749 — the mistaken-identity angle is the first
excuse anyone thinks of, so it reads as stock against a field of 2,749.
This round-2 line takes a fresher angle: the vacuum redefines its job so
the crime becomes the achievement. The sock is not missing; it is clean —
spotless, even. Gone, but spotless. Deadpan, three beats, kicker on the
last three words, every word working.
